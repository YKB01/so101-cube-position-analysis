# 四模型对照测试结果（deep vs R vs C vs C_trunc）

测试：2026-11-19 13:44–15:40，64 次（每模型 16 次，P1/P2 各 8 次），区块交替，盲测；协议 `protocol/four_model_test.md`。
解盲前核对了 key 的 SHA-256（`f117e9a7…`，与封存值一致）。分析脚本 `analyze_four_model.py`（预注册的比较）和 `analyze_four_model_explore.py`（探索性），输出在本目录和 `four_model_analysis/`。

## 1. 主要结果

| 模型 | P1 | P2 | 合计 |
|---|---|---|---|
| deep | 6/8 | 8/8 | **14/16（88%）** |
| R | 4/8 | 5/8 | 9/16（56%） |
| C | 4/8 | 6/8 | 10/16（62%） |
| C_trunc | 1/8 | 1/8 | 2/16（12%） |

| 比较（P1+P2，双侧 Fisher） | 成功率差（百分点） | Newcombe 95% CI | p | 性质 |
|---|---|---|---|---|
| **deep vs R** | +31 | [−0, +56] | **0.113** | **主要（预注册）** |
| deep vs C | +25 | [−5, +51] | 0.220 | 次要 |
| R vs C | −6 | [−36, +25] | 1.000 | 次要 |
| deep vs C_trunc | +75 | [+42, +88] | < 0.0001 | 探索 |
| C vs C_trunc | +50 | [+16, +71] | 0.009 | 探索 |
| R vs C_trunc | +44 | [+11, +66] | 0.023 | 探索 |

**对预注册预测的结论：**
- **主要预测（deep 高于 R）没有达到判定标准**：方向与预测一致、差距 31 个百分点，但 p = 0.113 > 0.05，CI 下界到 0。协议已说明 16 对 16 只有差距 ≥ 约 44 个百分点才显著，这次观察到的差距小于该门槛。
  结论只能是"没有证据表明 deep 与 R 有差别；数据与 deep 更好的方向相容，但不足以确认"，**不能**说 deep 优于 R，也不能说无差别。
- 次要预测 (a)（deep 与 C 无明显差别）：p = 0.22，未显著，但按协议不能由此证明无差别。
- 次要预测 (b)（R 低于 C）：**没有观察到**（9/16 对 10/16）。重测里 R 7/16、C 15/16 的差距没有重现，原因是这次 C 只有 10/16（见第 4 节），R 与重测一致（9/16 对 7/16，p = 0.72）。
- C_trunc 又一次很差（2/16；上次 0/16），显著低于另外三个模型。

分位置（探索性，8 对 8，均不显著，除含 C_trunc 的比较）：P1 deep 6/8、R 4/8、C 4/8；P2 deep 8/8、R 5/8、C 6/8。deep 在两个位置都不低于另外两者。

## 2. 失败类型

- deep 的接近最慢（第一次抓取 8.95 秒，对 R 的差 p = 0.001，对 C p < 0.001），合上次数最少。速度曲线见 `fig3_speed_aligned.png`，瞄准误差见 `fig4_aim_error.png`。
- 瞄准误差 x 在 deep、R、C 之间没有明显差别（p = 0.38–0.44），所以这次没有支持"deep 瞄得更准"。
- **注意**：合上次数和第一次抓取时间部分取决于结果（成功后提前结束、失败后反复尝试），不能当作成功率差别的独立解释，只作描述。

## 4. 场次间对照与时间

| 模型 | 本场 | 重测（11/14） | 截断对照场（11/14 晚） | Fisher p（本场 vs 之前） |
|---|---|---|---|---|
| C | 10/16 | 15/16 | 8/16 | 0.083（对重测）、0.722（对截断场） |
| R | 9/16 | 7/16 | — | 0.724 |
| C_trunc | 2/16 | — | 0/16 | 0.484 |

- C 三次分别是 15/16、8/16、10/16，场次间波动很大，C 的重测 15/16 看起来是偏高的一次；原因仍未解释（光照和相机偏移此前已排除）。
- **R 的前后半段**（事后看到的模式，探索性）：V01–V32 为 7/8，V33–V64 为 2/8（p = 0.041，未校正）；R 从第 11 个区块（V42）起连续 6 次失败。其他三个模型没有同样的趋势
  （deep 6/8 → 8/8，C 5/8 → 5/8，C_trunc 0/8 → 2/8）。这个模式是看完数据才发现的，没有预先假设；如果它是随机波动，则 R 的真实水平更接近重测的 7/16，而不是前半场的 7/8。
  不排除时间相关的原因，但本场没有任何协变量能解释（见下）。
- 首帧桌面灰度几乎恒定（均值 115–116，只有 V14 在亮态阈值 117.5 之上），**本场基本没有曝光状态的变化**，所以不能检验曝光状态与结果的关系；灰度与成功的相关在各模型内都不显著（|r| ≤ 0.35）。
  控制循环周期均值 33.53–33.57 ms，四个模型相同。放置误差最大 2.91 px，各模型均值 1.2–1.5 px。
- 日期：全部在同一天完成（2026-11-19），没有分日中断；日期因素无需另行拆分。

## 5. 局限
- 每个模型 16 次，一个种子；主要比较的功效只有约 50%–60%（差距为 40 个百分点时），这次 p = 0.113 与 deep 确实更好相容，也与小样本下的波动相容。
- 盲测被 C_trunc 的行为削弱（动作慢、抓不到）：操作者可能识别出 C_trunc 的编码；deep 的行为（接近慢）也有可能被识别。结果记录是在运行结束时按规则当场完成的。
- 两次试验级中断（电机总线通信错误，0 步，已重做），不影响组间比较；会话记录是事后重建的（见协议偏差日志）。
- R 后半场的失败连续出现是事后发现的模式，不能据此改变主要结论。

## 6. 可以说的与不能说的
- 可以说：deep 的成功率最高（14/16），与 R（9/16）和 C（10/16）的差都没有达到 0.05；C_trunc 明显最差，这次重复了上次的结果。
- 不能说：deep 优于 R（主要预测未达判定标准）；deep 与 C 无差别；"深回退数据让策略更好"的机制。deep 与 R 的数据在回退深度之外还有其他差别（见协议"局限"）。
- 如果要确认 deep 与 R 的差别，需要更多次数：按本场的成功率（88% 对 56%），每组约 30 次才能达到 80% 功效（正态近似的粗略估计）。
